# Debit Notes

[← Back to Documentation Index](../README.md)

Under Section 34 of the CGST Act, a **Debit Note** (`DN`) is issued by the supplier to *increase* the tax liability of an originally issued Tax Invoice.

Common scenarios include:
1. Accidental under-billing (e.g., charged ₹10,000 instead of ₹15,000).
2. Price revisions or escalation clauses triggered after invoice issuance.

## Creating a Debit Note

A Debit Note **must** reference an original Tax Invoice (`reference_invoice_id`).

```php
use AnjanTalukdar\GstInvoice\Facades\GstInvoice;
use AnjanTalukdar\GstInvoice\Data\InvoiceItemInput;

$taxInvoice = GstInvoice::taxInvoice()->find(1);

// We are issuing a debit note for the additional ₹5000 that was missed
$dnItems = [
    InvoiceItemInput::make('Price escalation correction', 5000.00, 1.0)
];

$debitNote = GstInvoice::debitNotes()->create($taxInvoice, $dnItems);
```

## Impact on GSTR-1

Debit Notes are automatically grouped with Credit Notes in the `CDNR` (Credit/Debit Notes Registered) tables of the GSTR-1 exports generated by `$gst->reports()`.
