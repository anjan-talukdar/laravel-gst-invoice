# Contributing

Thank you for considering contributing to the Laravel GST Invoice package!

## Development Process

1. Fork the repository.
2. Clone your fork locally.
3. Install dependencies using `composer install`.
4. Create a new branch for your feature or bug fix.
5. Write tests for your changes.
6. Ensure all tests pass by running `vendor/bin/phpunit`.
7. Submit a Pull Request.

## Code Style

This project follows PSR-12 coding standards. Please run a PHP linter before submitting PRs.

## Bug Reports

When filing bug reports, please include:
- Laravel version
- Package version
- PHP version
- Clear steps to reproduce the issue
- Expected behavior vs actual behavior
